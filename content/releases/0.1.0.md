### Directory
- **New:** Connect to a domain controller over LDAPS or StartTLS and read the directory into a snapshot you can explore offline.
- **New:** Browse organisational units as a tree, with users, groups and computers in place.
- **New:** Open the sample directory without connecting to anything, to see what SPYDR does before pointing it at your own.
- **New:** Re-crawl reads the directory again with the credentials already in memory, and tells you what moved since last time.

### Hygiene
- **New:** Score a directory against a set of checks — stale accounts, passwords that never expire, unconstrained delegation, privileged group sprawl.
- **New:** Every finding names the objects it is about, so a score is never just a number.

### Web
- **New:** See group membership as a graph, with nesting drawn as edges rather than described in words.

### Pathfinder
- **New:** Ask how one account reaches a privileged group, and get every path between them, with the answer stated in a sentence before the paths are drawn.

### Timeline
- **New:** Every read is compared against the one before it, and what changed is recorded — members added and removed, accounts enabled and disabled, flags flipped.
- **New:** A branching graph of the directory's history, so a change can be traced to the read that first saw it.
- **New:** Generate a sample timeline from Settings, to see the shape of it without waiting weeks for real history.

### Reports
- **New:** Export a hygiene report as a PDF, laid out for sending to someone who will not open SPYDR.

### Settings
- **New:** Hygiene thresholds, connection defaults, reports, privacy, appearance and updates, reachable before connecting to anything.
- **New:** Choose a theme, including a black-and-white Minimal in light and dark.
- **New:** Usage telemetry, off unless you switch it on, and it shows you the exact payload before sending.

### Platform
- **New:** Read-only by design. SPYDR binds, searches, and disconnects — there is no code in it that can modify a directory.
- **New:** The bind password lives in memory for the session and is never written to a snapshot, a log, or an error message.
- **New:** A built-in guide behind the ? button, covering every workspace, tool and concept.
- **New:** SPYDR is activated with a free licence key, checked once and then about monthly. If that check falls due while you are offline it keeps working and says so.
